Ethical Hacking भनेको के हो?

Ethical Hacking भनेको कम्प्युटर, नेटवर्क र वेबसाइटमा रहेका सुरक्षा कमजोरीहरू सम्बन्धित व्यक्तिको अनुमति लिएर पहिचान गर्ने प्रक्रिया हो। यसको उद्देश्य प्रणालीलाई सुरक्षित बनाउनु हो।

हाम्रो Course Lessons

Lesson 1: Introduction to Cyber Security

Cyber Security के हो? यसले कम्प्युटर, मोबाइल, नेटवर्क र डाटालाई कसरी सुरक्षित राख्छ भन्ने सिक्नुहोस्।

Lesson 2: Networking Basics

IP Address, DNS, Router, Server र Network का आधारभूत कुराहरू सिक्नुहोस्।

Lesson 3: Linux Fundamentals

Linux Operating System, Terminal र आधारभूत Command हरू प्रयोग गर्न सिक्नुहोस्।

Lesson 4: Web Security

वेबसाइट कसरी सुरक्षित बनाउने र सामान्य सुरक्षा कमजोरीहरू कसरी बुझ्ने भन्ने सिक्नुहोस्।

Lesson 5: Ethical Hacking Lab

अनुमति प्राप्त अभ्यास वातावरणमा सुरक्षा परीक्षण, कमजोरी पहिचान र रिपोर्ट लेख्ने अभ्यास गर्नुहोस्।

यो Course सिकेपछि के गर्न सकिन्छ?

  • Cyber Security को आधारभूत ज्ञान प्राप्त गर्ने।
  • Networking र Linux बुझ्ने।
  • वेबसाइटको सुरक्षा सिद्धान्त सिक्ने।
  • सुरक्षित अभ्यास Lab मा परीक्षण गर्ने।
  • Security Report तयार गर्न सिक्ने।

महत्त्वपूर्ण सुरक्षा नियम

अभ्यास गर्दा आफ्नै कम्प्युटर, आफ्नै Lab वा स्पष्ट अनुमति प्राप्त प्रणाली मात्र प्रयोग गर्नुहोस्। अनुमति बिना अरूको वेबसाइट वा नेटवर्क परीक्षण नगर्नुहोस्।
