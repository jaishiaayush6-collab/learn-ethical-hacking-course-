1. Linux भनेको के हो?

Linux एउटा Open Source Operating System हो। यो Server, Desktop, Embedded Systems तथा अन्य धेरै क्षेत्रमा प्रयोग गरिन्छ।

2. Linux Distributions

Ubuntu, Debian, Fedora, Linux Mint, Kali Linux र Arch Linux लोकप्रिय Linux Distributions हुन्।

3. Basic Linux Commands

हालको Directory हेर्न:

pwd

फाइल तथा Folder हेर्न:

ls

Directory परिवर्तन गर्न:

cd Documents

Folder बनाउन:

mkdir myfolder

फाइल बनाउन:

touch example.txt

फाइल पढ्न:

cat example.txt

Terminal सफा गर्न:

clear

हालको प्रयोगकर्ता हेर्न:

whoami

4. Linux File System

/home - User Files

/etc - Configuration Files

/var - Variable Data

/tmp - Temporary Files

/bin - Essential Commands

5. Linux Security

Linux मा User Permissions, Updates, Firewall र सुरक्षित Password प्रयोग गर्नु महत्त्वपूर्ण हुन्छ।
