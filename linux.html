Explore Linux operating systems and command-line fundamentals.

01. What is Linux?

Linux is an open-source operating system kernel. Linux-based operating systems are widely used in computers, servers, embedded devices and cloud infrastructure.

02. Linux Distributions

  • Ubuntu
  • Debian
  • Fedora
  • Linux Mint
  • openSUSE
  • Kali Linux

Each distribution provides different tools and experiences.

03. Basic Linux Commands

Display current directory:

pwd

List directory contents:

ls -la

Change directory:

cd Documents

Create a folder:

mkdir learning

Display current username:

whoami

Display system information:

uname -a

Display available disk space:

df -h

Display memory information:

free -h

04. Linux File System

  • /home – User directories.
  • /etc – Configuration files.
  • /var – Variable application data.
  • /tmp – Temporary files.
  • /usr – User applications and resources.
  • /bin – Essential user commands.
  • /boot – Boot-related files.
  • /dev – Device files.

05. File Permissions

Linux uses permissions to control access to files and directories.

ls -l

Permissions include:

  • r – Read
  • w – Write
  • x – Execute

Permission groups include owner, group and others.

06. Package Management

On Debian and Ubuntu systems, APT is commonly used to manage software packages.

apt search package-name
apt show package-name

Use package installation and system update commands only with appropriate authorization.

07. Linux Learning Roadmap

  1. Understand Linux distributions.
  2. Learn the terminal.
  3. Explore files and directories.
  4. Understand users and permissions.
  5. Study processes and services.
  6. Learn networking basics.
  7. Practice system administration.
