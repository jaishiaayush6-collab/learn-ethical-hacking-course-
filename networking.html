1. Networking भनेको के हो?

Networking भनेको दुई वा दुईभन्दा बढी कम्प्युटर तथा डिजिटल उपकरणहरूलाई आपसमा जोडेर सूचना र स्रोतहरू आदानप्रदान गर्ने प्रक्रिया हो।

2. Types of Networks

LAN: Local Area Network। सानो क्षेत्रभित्र प्रयोग हुने नेटवर्क।

MAN: Metropolitan Area Network। सहर वा ठूलो क्षेत्र समेट्ने नेटवर्क।

WAN: Wide Area Network। ठूलो भौगोलिक क्षेत्र जोड्ने नेटवर्क।

3. IP Address

IP Address नेटवर्कमा कुनै उपकरण पहिचान गर्न प्रयोग हुने डिजिटल ठेगाना हो।

IPv4 र IPv6 IP Address का दुई प्रमुख संस्करण हुन्।

4. Networking Devices

Router, Switch, Modem, Hub, Access Point र Network Interface Card नेटवर्कमा प्रयोग हुने उपकरणहरू हुन्।

5. Networking Protocols

HTTP, HTTPS, TCP, UDP, DNS, DHCP र FTP नेटवर्कमा प्रयोग हुने प्रमुख Protocol हरू हुन्।

6. OSI Model

OSI Model मा सात तह हुन्छन्:

1. Physical

2. Data Link

3. Network

4. Transport

5. Session

6. Presentation

7. Application
