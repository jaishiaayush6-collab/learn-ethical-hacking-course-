1. Web Security के हो?

Web Security भनेको Website, Web Application र त्यसमा रहेका डाटालाई अनधिकृत पहुँच तथा डिजिटल जोखिमबाट सुरक्षित राख्ने प्रक्रिया हो।

2. HTTPS Security

HTTPS ले Browser र Server बीचको सञ्चारलाई TLS मार्फत सुरक्षित बनाउँछ। यसले डाटाको गोपनीयता र अखण्डता कायम राख्न सहयोग गर्छ।

3. Common Web Security Risks

• SQL Injection

• Cross-Site Scripting (XSS)

• Cross-Site Request Forgery (CSRF)

• Broken Authentication

• Security Misconfiguration

यी जोखिमहरू बुझेर आफ्नो Website सुरक्षित बनाउन सिक्नुहोस्।

4. Password Security

लामो र फरक Password प्रयोग गर्नुहोस्। Multi-Factor Authentication (MFA) सक्षम गर्नुहोस्। Password अरूसँग साझा नगर्नुहोस्।

5. Website Protection

Website Updates, HTTPS, Secure Authentication, Input Validation र नियमित Backup प्रयोग गर्नुहोस्।

6. Ethical Hacking

Ethical Hacking भनेको स्पष्ट अनुमति लिएर प्रणालीको सुरक्षा कमजोरी पहिचान गर्ने प्रक्रिया हो। अभ्यास सधैँ आफ्नै Lab वा अनुमति प्राप्त वातावरणमा मात्र गर्नुहोस्।
