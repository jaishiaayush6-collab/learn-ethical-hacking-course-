Cyber Security

Understand digital threats and learn how to protect information.

01. What is Cyber Security?

Cybersecurity is the practice of protecting computers, networks, applications and information from unauthorized access, disruption and misuse.

02. The CIA Triad

Confidentiality

Information should only be accessible to authorized people.

Integrity

Information should remain accurate and trustworthy.

Availability

Systems and information should be accessible when needed.

03. Common Cyber Threats

Phishing

Fraudulent messages designed to trick people into revealing information.

Malware

Software designed to harm, disrupt or gain unauthorized access.

Ransomware

Malicious software that can deny access to data until a demanded payment is made.

Social Engineering

Manipulation that attempts to make people reveal confidential information.

Weak Passwords

Poor password practices can expose user accounts.

04. Website Security

  • Use HTTPS with valid TLS certificates.
  • Validate and sanitize user input.
  • Use secure authentication.
  • Protect sensitive information.
  • Keep frameworks and libraries updated.
  • Use appropriate security headers.
  • Back up important information.

05. Password Safety

  • Use long and unique passwords.
  • Never reuse passwords across important accounts.
  • Enable multi-factor authentication.
  • Use a trusted password manager.
  • Never share verification codes.

06. Ethical Cybersecurity

Ethical security learning must follow permission, law and responsible disclosure.

  • Practice only in authorized labs.
  • Never access other people's accounts.
  • Do not test public websites without permission.
  • Report vulnerabilities responsibly.
  • Respect privacy and personal data.
